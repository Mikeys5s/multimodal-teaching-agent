## 登记项 D-01：图可视化实际为自研纯 SVG，未使用 `Cytoscape.js`

### 一、事实（逐条附路径，均已实读确认）

**事实 1 · SPEC 把 `Cytoscape.js` 写成了冻结依赖，且有两处一致表述**

- 技术选型冻结表（`SPEC.md` 约 325 行）：

  > | 图可视化 | **Cytoscape.js（DAG）** / AntV G6 | 知识图谱与学习路径 | ✅ |

- 逐日任务表 D6 那行（`SPEC.md` 约 1175 行）：

  > 知识图谱页骨架（**Cytoscape.js**）

→ 两处一致，**不是笔误**。

**事实 2 · 实际实现是自研纯 SVG + 自研 DAG 拓扑分层布局**

| 文件 | 它在做什么 |
|---|---|
| `frontend/src/components/graph/GraphCanvas.tsx` | **纯 SVG 手写画布**。节点是 `<rect>` + `<text>`，边是 `<line>`，箭头是 `<defs><marker>`；平移/缩放自实现（`handlePointerDown/Move/Up` + 原生 `wheel` 监听 + 光标锚定的 `zoomAt`） |
| `frontend/src/components/graph/dagLayout.ts` | **自研 DAG 分层布局**：① Kahn 拓扑序做**最长路径分层**（层号 = 所有前置层号最大值 + 1，入度 0 落第 0 层）② 层内**重心排序**（下扫 4 轮 + 上扫 4 轮压交叉）③ 层 → x（左→右即先修在前），层内序号 → y |

**事实 3 · `cytoscape` 依赖根本不存在**

`frontend/package.json` 的 `dependencies` 只有四项：`lucide-react` / `react` / `react-dom` / `react-router-dom`。
在**整个 `frontend/` 目录（含 `package-lock.json`）** 搜索 `cytoscape`：**零命中**。

- **怎么复现**：`grep -rn cytoscape frontend/ | wc -l` → 期望 `0`；`grep -n cytoscape SPEC.md` → 期望 2 处命中（即事实 1）。

### 二、为什么不改代码去补依赖（而是登记差异）

结论：**补一个 `cytoscape` 依赖是净损失**，四条理由：

1. **零依赖直接服务于「离线构建 / 运行期零依赖」这条架构约束。**
   前端构建要在云主机上跑，`npm ci` 的网络本来就要靠镜像源绕。
   **每多一个运行时依赖，就多一处构建失败面** —— 而构建失败在 9/24 录制那天是致命的。
2. **自研布局能保证「前置在左」这条语义，第三方库不保证。**
   最长路径分层让「层 → x」天然把先修知识点放左边 —— 这正是我们讲「学习路径」时的视觉论点。
   换成 Cytoscape 还要额外挂 `dagre` / `klay` 扩展，且**不保证**这个语义。
3. **现有实现里已长出两个「教学语义」的可视证据，换库会丢掉。**
   - `dagLayout.ts` 的 `LayoutEdge.backEdge`（`to.layer <= from.layer`）把**本该不存在的逆向边画成红色告警**
     —— 这是「**教学依赖图必须无环**」这条工程不变量的**图上可视证据**。
   - `GraphCanvas.tsx` 对 `needs_review` 节点用**虚线描边 + 琥珀色角标**
     —— 这是「**AI 预抽取 + 人工校验**」主创新点在界面上的落点，也是录制纪律④「视频里必须演人工复核」的画面基础。
4. **风险收益比明确为负。** 前端已合并进 `main` 并重新部署，此时换图库等于把
   `GraphCanvas` / `dagLayout` 推倒重来，再走一次构建 + 部署 + 交互回归；
   收益只是「文字更一致」，成本是「录制前的稳定版本被扰动」。

### 三、建议处置：**改 SPEC 文字，不改代码**

- **建议动作**：把 `SPEC.md` 里两处 `Cytoscape.js` 表述更新为实际实现，例如
  「图可视化 | **自研纯 SVG + 自研 DAG 拓扑分层布局（零依赖）** | 需要保证「前置在左」与「无环」两条语义可在图上直接验证 | ✅」
- **流程**：先在 Issue 里知会 → 建 `docs/` 分支 → 至少 1 人 review（本文件不代替该流程）。
- **明确不做的事**：**不动 `frontend/` 任何代码**，**不往 `package.json` 加依赖**。
  这一条要写清楚，避免答辩前有人「顺手补齐 SPEC」反而把发布版改坏。

### 四、如果评委问起，怎么回答

**一句话口径**：

> 「图这一块我们**没有用 Cytoscape**，是**自研的纯 SVG + 自研的 DAG 拓扑分层布局**。
> 因为我们要的不只是『把图摆出来』，而是要让**『前置在左』和『图必须无环』这两条语义在界面上可以直接被验证**。
> 这条与 `SPEC.md` 早期文字的差异**已经登记在仓库文档里**（`docs/spec-diff-log.md`）。」

**接着展开三点（每点都能当场指给人看）**：

1. **分层是算出来的**：最长路径分层 —— 层号 = 所有前置的最深层级 + 1，由 Kahn 拓扑序保证算层时前置都已定层。
   → **「先修在前」不是排版巧合，是算法的结果。**
2. **环路看得见**：出现指向同层或更浅层的边，会被标成**红色告警**。
   → 这是把「教学依赖图必须无环」当**工程不变量**保证的**可视证据**。
3. **零运行时依赖**：`frontend/package.json` 的 `dependencies` 只有 **4 个**。

**措辞提醒**：**不要说「我们换掉了原本计划用的库」**（听起来像妥协）；
要说「**计划里的库最终没有引入，因为自研实现能把语义讲得更清楚，并且零依赖**」（这是设计判断）。
