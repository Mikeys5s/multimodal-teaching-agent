```
   （例：`.learnbuddy/_gh/seed_in_container.py` 就是按这个做的）
```

### 事实 2 · 部署有自检，**必须看它的结论**

```
`bash scripts/deploy.sh` 结束时会给「部署后自检 6 项」。
⚠️ **`docker compose up -d` 不会因 build 失败而报错退出** ——
   它只是没换镜像，**容器还在跑旧代码，而外网照样 200**。
⇒ **只有"代码身份"那项（本地清单哈希 vs 容器哈希）能发现这种情况。**
⇒ **2026-10-10 就发生过一次**（pip 从阿里云拿不到包 ⇒ 构建失败 ⇒ 静默跑旧代码）。
```
