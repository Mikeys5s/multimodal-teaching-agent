**⭐ 这不是"检索不到"，是"被判成材料外"** —— 系统的回答是：

> **材料里没有这个内容。**
> 我翻了当前入库的材料，没有找到能支撑这个问题的段落 —— 所以我不答，**不猜**。

机制本身是**对的**（"宁缺毋错"的落点），**触发条件是错的**。

### 一个可检验的假设（供 P2 定位，不是结论）

失败题**几乎全是"原理 / 关系型"提问**（本质区别、为什么、难在哪、看哪些指标），
而命中题**多是"术语 / 定义型"**（什么是、有哪些字段）。

⇒ 若越界判定是按**与知识点名的词面/关键词重合度**阈值做的，那"为什么…"这类问题
**天然缺少与标题重合的实词**，就会掉到阈值以下 → 被判越界。
**锚点答案不用问，`Q28` 就是 9/21 抽样时已报过的同一个失败样本** —— 它不是偶发。

**命中构成**：`exact 命中 11 / 仅同章命中 11 / 未命中 8`（章节级判据，见 `_judging.A3-1_criterion`）。

## 四、边界（这份记录**不能**证明什么）

1. **不能证明"回答质量"**：本跑测只判 `retrieved` 落在哪一节与 `is_out_of_scope`（这是 `_judging` 明确要求的判据）。
   `⚠️_不要用` 那条写得很清楚：**不许**用"回答里出现期望关键词"当命中判据 —— 那会把"检索到但答偏"也算通过。
2. **A3-1 的章节级判据是"宽松下界"**：同章即算命中。若改成 `exact` 判据，命中是 **11/30 = 36.7%**。
   ⇒ **73.3% 是乐观口径**，别把它当成"接近达标"。
3. **一次跑测、单一时点**：知识点名有噪声（重名率 3.5–4.6×）、`/learning-path` 与检索都吃同一批数据。
   数据一变（如 9/24 后的去重），**这两组数字都要重跑**。
