### ② 依赖怎么管？

| 选项 | 评价 |

### ③ ⭐ 主键 ID 怎么生成？（**今晚最需要拍板的技术决策**）

这不是风格问题 —— **它直接决定验收项 A2-7「同输入可复现」能不能成立**。

| 选项 | 形态 | 优 | 劣 |
|---|---|---|---|
| A · 随机短 ID | `kp_a1b2c3d4` | 实现最简单 | ❌ **重跑同材料得到不同 ID** → A2-7 受损、重跑 diff 无意义、调试时对不上号 |
| B · 确定性路径式 ID（**推荐**） | `kp_a1b2c3d4_5_2_007`<br>（材料 hash 8 位 _ 章 _ 节 _ 序号） | ✅ **同输入 → 同 ID**，A2-7 天然成立；重跑可逐条 diff（正好支撑 §5.2 F2.9「可重跑」）；**一眼看出归属** | ID 较长；材料内容变了 ID 会全变（但这是应该的） |
| C · 自增整数 + 业务唯一键 | `id=1,2,3...` + `UNIQUE(material_id, section_id, seq)` | 查询快、外键轻 | 自增值在重跑时不稳定（除非每次都清库重建） |

**推荐 B**，理由：
- 我们的抽取是**离线、可反复重跑**的（§4.8），"重跑前后有什么变化"是必须能回答的问题
- A2-7 是硬指标，而 ID 稳定是它的前提
- `material_id` 本身用 **文件内容 hash**（`mat_<sha1[:8]>`）生成 —— 正好和成本控制 C2 的"文件 hash 唯一索引"是同一个东西，不重复造

**如果你更看重短 ID 和实现简单**，选 A 也行，但请接受 A2-7 要另找方式举证。

### 步骤 2 · 核心 6 张表（约 2 小时）

**为什么分批**：这 6 张支撑 M1 与 M4，是刚性需求；另外 8 张（`kp_examples`/`kp_misconceptions`/`kp_embeddings`/`questions`/`qa_sessions`/`qa_turns`/`jobs`/`llm_calls`）分别在 D2 / D6 / D8 才用得上。**先把关键的做扎实，比 14 张都做一半强。**

| 表 | 关键约束（**一个都不能漏**） | 支撑的验收项 |
|---|---|---|
| `materials` | `file_hash` UNIQUE（成本控制 C2）；`source_type` CHECK；`parse_status` CHECK；`uncertain_notes` | A1-4、A1-7 |
| `material_blocks` | `UNIQUE(material_id, seq)`；`page_no`/`line_start`/`line_end`；`content_md` NOT NULL | **A1-6 页码锚点** |
| `chapters` | `UNIQUE(material_id, number)` | A2-1 |
| `sections` | `chapter_id` NOT NULL FK；`UNIQUE(chapter_id, number)` | **A2-1 三级结构完整率 100%** |
| `knowledge_points` | **`section_id` NOT NULL**、**`source_quote` NOT NULL**、`difficulty CHECK 1..5`、`seq` | **A2-1 / A2-3 溯源覆盖率 100%** |
| **`kp_prerequisites`** | **`reason` NOT NULL**、`CHECK(kp_id != prereq_kp_id)`、`relation_type CHECK IN('hard','soft')`、`evidence_quote`、`source_channel`、`needs_review`、**`pruned`（软删除标记）** | **B1-2 / B1-4 / B1-5** |

**⭐ 重点提醒**：`kp_prerequisites` 是你 **D7 的主战场**（创新点主创在你这里）。
- `pruned` **必须是软删除标记**，不能物理删除 —— 它让"检出并剪除了 N 条成环边"变成可展示的证据（比只报"环数 0"有说服力，见 `docs/innovation.md`）
- `reason` NOT NULL 是 B1-5 的载体，**不能为了好写而改成可空**

**产出**：`backend/app/models/*.py`
**验证**：`Base.metadata.tables` 能列出 6 张表
