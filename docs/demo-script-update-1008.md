## 一、原脚本最核心的一镜，**现在可以演得更硬**

### 原计划（`demo-script.md` L47 / L175）

> 导入候选边 → **采纳一条** → 切 `/path` 指给镜头看 **路径从 1 步变 3 步**

**当时的风险项**（L185）：🔴 **hard 候选边 0 条 ⇒ 演不出来**。

### 现在的情况（**实测**）

**Ch06 补了 8 条 hard 前置边**，线上已验证：

```
/api/learning-path?kp_id=kp_cf6fcaa0_000_000_028   →  **4 步**
                         kp_cf6fcaa0_000_000_026   →  3 步
                         kp_cf6fcaa0_000_000_024   →  2 步
```

**路径链是真实的因果**，例如 `_028` 的 4 步：
```
FIFO 的问题 → bit-by-bit 轮转 → FQ 的第一点观察 → work conserving（链路不空闲）
```

**而且每条边都带 `reason` + `evidence_quote`（材料原文）**：
```
[hard] FIFO 的问题 → FQ 的动机
  reason: 公平队列是为解决「FIFO 不区分流量来源」这个问题而提出的…
  quote : "The main problem with FIFO queuing is that it does not discriminate
           between different traffic sources" / "What we really want is bit-by-bit round-robin"
```

**⇒ 建议**：**「路径会变」这一镜可以不依赖"采纳候选边"了** ——
直接打开 Ch06 的点，**指给镜头看那 4 步 + 每步的理由**，
**这本身就是「教学依赖图真的在约束学习顺序」的可见证据**。

**⭐ 还有一条最硬的边是跨章的**：`滑动窗口 → 慢启动的第二种场景`
—— **材料原文自己写了 "Recall how TCP's sliding window algorithm works"**，
**等于它承认这是前置**。如果镜头能给这条一个特写，比任何台词都强。

## 二、⭐ 今天修好的「多轮答疑」—— **我认为它该进正片**

### 为什么它值得进

**它一次演示就能同时证明三件 SPEC 的硬规则**，而且**全部是肉眼可见的状态变化**：

| 轮次 | 实测输出 | 证明了什么 |
|---|---|---|
| 第 1 轮 | 「先想一个问题：…（不用急着答对）」 | **首轮绝不给答案**（苏格拉底铁律） |
| 第 2 轮 | 给出提示 | **提问 → 提示** 的状态机 |
| 第 3 轮 | 「**行，连续两次没答上，我直接讲。**」 | ⭐ **连续 2 次答不上 ⇒ 降级直讲（由代码层强制）** |
| 第 4 轮 | 「**材料里没有这个内容。我不答，不猜。**」 | ⭐ **宁缺毋错 / 幻觉率为 0** |

**⇒ 这四轮连起来，是一条完整的"教学逻辑"演示**：
**不直接给答案 → 给提示 → 学生真的卡住才讲 → 超纲就承认不知道。**

### 怎么拍

- **一个会话连问 4 次**（**别重开会话**，状态机是在会话里推进的）
- **右下角 `diagnosis` 面板**（涉及知识点 / 卡在哪 / 下一步练习）**每轮都在变** ——
  这是「每轮输出三件事」那条规则的可视证据
- **第 3 轮那句「连续两次没答上，我直接讲」** 值得一个停留 ——
  它说明**这不是模型随便聊，是状态机在按规则走**

**⚠️ 一个如实说明**：那时**答疑正文里会抛英文原文片段**
（例如「先想一个问题：如果 which time the congestion window is divided by 2…」）。
**根因是知识点的名字/引用是被截断的英文句片段**，我判断**决赛期不动核心链路**。
**如果镜头扫到了，不用掩饰** —— 甚至可以说一句「
**这里引的是材料原文，我们的溯源是逐字引用的**」，**把它转成优势**。

## 三、两处新的「一眼可见」

### ① 重复组标注

629 个知识点里 **462 个是副本**（同一段材料内容被抽了多遍）。
现在详情/列表上会多三个字段，**前端可以显示**：
「**本知识点在材料中出现 35 处，已合并显示**」

**⚠️ 文案纪律**：**写「已合并显示」，绝不写「已去重」** ——
**我们只做了标注，没删数据**。写"已去重"就是假的。

**怎么拍**：点开两个**看起来一样**的点，展示它们**指向同一个代表** + 「35 处」那个数字。
**这反而能体现「我们知道自己的数据有问题，并且诚实地标出来了」**。

### ② 可读标题

629 条里 **438 条**现在有可读标题（从材料的**小节标题**或**首句**提炼，**不编造**）。

**怎么拍**：图谱页上**不再全是 `There` / `3` / `If network latency`**。
**⚠️ 剩下 191 条仍是原名**（那些 `summary_md` 本身就是被截断的英文句片段）——
**照实说就好**：「没有可靠标题的，我们**就显示原名**，不造一个看起来像标题的东西」。
