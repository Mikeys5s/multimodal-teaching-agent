## 一、怎么提部署请求

**在 GitHub/Gitee 的 Issue 里提**（或在该分支相关的 Issue 下评论），标题/正文**含「部署请求」**，并附上：

```
【部署请求】
分支：feat/xxx
commit：<sha>
改了什么：（一句话）
怎么验的：（贴自检输出）
```

**⚠️ 只有分支推上去了不算提请求** —— 必须**贴出自检证据**，否则巡检会当成"没自检"。

## 二、自检四步（**缺一项会被打回**）

### ① 后端测试全过

```bash
cd backend && .venv/Scripts/python.exe -m pytest tests -q --tb=line -p no:warnings
# 期望：全部通过（只有 skip 可以）
```

### ② 索引完整（**本仓库的已知坑**）

```bash
git ls-files | wc -l
git ls-tree -r HEAD --name-only | wc -l
# ⚠️ 这两个数必须相等
ls -la .git/*.lock 2>/dev/null    # 不该有 0 字节的锁文件
```

**为什么**：本机的 `.git/index` 曾**静默变旧**过两次 ——
`git status` 会把 HEAD 已跟踪的文件报成「暂存删除 + 未跟踪」，
而 `git commit -am` 会**真把这些文件删进历史**。
**⇒ 发现不等就先 `git reset`（工作区不动），别提交。**

### ③ 前端能构建（改了前端才需要）

```bash
cd frontend && npm ci && npx vite build 2>&1 | tail -5
# 期望：build 成功
```

### ④ 提交说明写清「改了什么 / 怎么验的」

```bash
git log -1 --format="%s%n%n%b"
# ⚠️ 只写 "fix: 修了个 bug" 的，会被打回
```

## 三、⚠️ 两个**必须知道**的部署坑

### 坑 1 · **pip 索引源不能改**

```dockerfile
# Dockerfile 里必须是清华源：
ARG PIP_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple/
```

- **别换回阿里云** —— 它的 `simple/` 索引**缺 PEP 658 的 `.metadata`**：
  索引页**列了**这个包、**直连 `.whl` 也是 200**，**但 pip 取 `.metadata` 就是 404**
  ⇒ 整条构建失败。（**表现极具误导性，别自己去试。**）
- **别加 `PIP_EXTRA_INDEX_URL`** —— 那是「**两个源一起找**」，
  会让 pip 对**每个包**都去官方源等一次 20 秒超时
  ⇒ **构建从 5 分钟变成 36 分钟且卡死**。

### 坑 2 · 「部署成功」≠「代码生效」

```
若镜像构建失败，`docker compose up -d` 不会报错退出
⇒ 容器继续跑旧代码，而外网照样 200 ⇒ 只看接口通不通是发现不了的
```

**正确判据（两选一，都要看产物而不是看日志）**：

```bash
# ① 镜像的创建时间应该是刚刚
ssh xizhi 'docker images xizhi --format "{{.ID}} {{.CreatedAt}}"'
# ② 部署脚本自检里的「代码身份」项：本地清单哈希 == 容器清单哈希
```

## 四、巡检会做什么（**你知道流程就不会被卡**）

```
每小时：
  ① 查 Gitee 有没有新提交 / 未合并分支 / 带「部署请求」的 Issue
  ② 没有变化 ⇒ 静默（不打扰任何人）
  ③ 有请求 ⇒ 核对 §二 的四项自检
       · 齐 ⇒ 合并 → 部署 → 全链路复检（40 项）→ 汇报美佳 + 在 Issue 下回执
       · 缺 ⇒ **不部署**，在 Issue 下要求补，并告知美佳
```

## 五、出问题怎么办

| 情况 | 怎么办 |
|---|---|
| 部署失败 | 巡检会**立刻报美佳**（含失败原始输出）；**别自己重试**，先定位 |
| 线上坏了要回滚 | 数据库备份在容器 `/data/xizhi.db.bak-*`；镜像可用上一个 tag |
| 不确定自己的改动安不安全 | **先别提部署请求**，在 Issue 里问 |

**⚠️ 最后一条纪律**：**不确定就停。** 宁可不动，也不要线上出问题 ——
**离截止只剩几天，线上是评委要看的东西。**
